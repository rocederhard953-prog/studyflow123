# StudyFlow 2.0

Многопользовательский учебный планировщик: личные аккаунты, привычки, домашние задания с фотографиями, расписание, оценки, шпаргалки, карточки, цели, календарь, Pomodoro, аналитика, виджеты и Telegram-уведомления.

## Быстрый запуск локально

Требуется Python 3.11+.

```bash
python -m venv .venv
# Linux/macOS
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python start.py
```

Открой `http://localhost:8000` и создай аккаунт. База и папка загрузок создаются автоматически.

## Развёртывание на хостинге

1. Загрузи в новый Git-репозиторий всё содержимое архива. В корне должны находиться `Dockerfile`, `Procfile`, `requirements.txt`, `start.py`, `app.py`, `bot.py` и папка `static`.
2. Выбери запуск через Dockerfile, если платформа поддерживает Docker. Иначе укажи команду запуска `python start.py` и установку зависимостей `pip install -r requirements.txt`.
3. Добавь переменные окружения из раздела ниже.
4. Подключи постоянный диск/volume и укажи `DATA_DIR` как путь его монтирования. Без постоянного диска SQLite-база и фотографии могут исчезнуть при пересборке или перезапуске контейнера.
5. Убедись, что приложение слушает переменную `PORT`, которую предоставляет хостинг. Если хостинг не передаёт её, приложение использует порт 8000.
6. Проверь `https://ТВОЙ-ДОМЕН/api/health` — должен вернуться JSON с `"ok": true`. Затем открой сайт и зарегистрируй пользователя.

### Переменные окружения

| Переменная | Обязательна | Значение |
|---|---|---|
| `DATA_DIR` | Для постоянного хранения рекомендуется | Путь к постоянному диску, например `/app/data` |
| `COOKIE_SECURE` | Для HTTPS рекомендуется | `1` |
| `MAX_UPLOAD_MB` | Нет | `8` |
| `TELEGRAM_BOT_TOKEN` | Только для Telegram | Токен от `@BotFather` |
| `DATABASE_URL` | Нет | Не заполнять при использовании SQLite; для PostgreSQL — URL подключения |
| `PORT` | Обычно задаёт хостинг | Не задавать вручную, если платформа сама предоставляет порт |

Приложение не требует `APP_PASSWORD`, `SESSION_SECRET`, домен или заранее заданный порт. Сессии создаются криптографически случайными токенами, а в базе хранится только их хеш.

## Telegram

1. Создай бота через `@BotFather`.
2. В переменную `TELEGRAM_BOT_TOKEN` вставь выданный токен целиком.
3. Перезапусти приложение.
4. Зарегистрируйся на сайте, открой раздел Telegram и нажми «Получить код».
5. Напиши боту `/start`, затем `/link КОД`.

Команды: `/today`, `/habits`, `/done ID`, `/undo ID`, `/homework`, `/task ID`, `/schedule`, `/tomorrow`. Интервал напоминаний и тихие часы настраиваются отдельно для каждого аккаунта. Для long polling должен работать только один экземпляр Telegram-процесса. При использовании нескольких web-инстансов запускай Telegram worker отдельно в одном экземпляре.

## Важные настройки

- `COOKIE_SECURE=1` включай, когда сайт доступен через HTTPS. При локальном HTTP-тестировании можно временно поставить `0`.
- `DATA_DIR` должен указывать на постоянное хранилище, доступное на запись.
- SQLite подходит для одного экземпляра приложения. Для нескольких web-инстансов используй PostgreSQL через `DATABASE_URL`.
- Не публикуй токен Telegram и не добавляй `.env` в Git.
- Изображения ограничены `MAX_UPLOAD_MB`; проверяется MIME-тип и сигнатура файла.

## Проверка состояния

`GET /api/health` — публичная проверка доступности приложения. Swagger API доступен по `/docs`.
