# Приложение, уведомления и учебные инструменты

## Что добавлено

- Устанавливаемое веб-приложение с чёрной иконкой луны, manifest и service worker. Favicon SVG и PNG, отдельная иконка для iPhone.
- Web Push: подписки нескольких устройств, тест отправки, отключение устройства, история и отметка прочитанного, счётчик и приватное содержание push. Выбор каналов отдельно для ДЗ, привычек, целей и остальных напоминаний. Тихие часы используют часовой пояс профиля.
- Серверная отправка по существующим фиксированным и относительным напоминаниям. ДЗ содержит предмет, срок и ссылку на материалы конкретного задания. Для целей — ежедневное напоминание в 09:00.
- План подготовки: темы, дни занятий, дата экзамена, ручной перенос и выполнение занятий.
- Шаблоны и повторяющиеся задания. Просроченное повторение создаёт одно актуальное задание, а не лавину пропущенных копий.
- Материалы задания: фото, заметки, шаги, доска и помощник. Распознавание фото использует существующий настроенный ИИ и его лимиты; результат нужно проверить перед сохранением.
- Нагрузка по дням с переносом сроков, архив выполненных решений с поиском, прогресс освоения тем.
- История последних 12 серверных состояний доски с общим пределом 4 МБ. Восстановление проходит через штатное автосохранение и проверку ревизии.
- Экспорт условия и видимой области доски через системную печать в PDF. Для доски открыть её и нажать PDF; печать не меняет сохранённое решение.
- Корзина заданий, целей, шпаргалок и заметок. У задания восстанавливаются записи фотографий, шаги и доска; существующие файлы не удаляются при переносе в корзину.
- Паузы привычек с сохранением истории и исключением паузы из запланированных дней.
- Плотность интерфейса, минималистичные обложки предметов, безопасное оформление формул KaTeX и блоков кода, полноэкранные фото с масштабом и поворотом.
- Переход от карточки задания к материалам, реакция стекла на курсор, прорисовка прогресса, свет активных островов, спутник и антенна обсерватории. Системное reduced motion продолжает учитываться; новый режим из пункта 30 не добавлен.

## Включение Web Push на хостинге

1. Установить обновлённый requirements.txt.
2. Один раз выполнить `python generate_push_keys.py` на доверенном сервере. Вывод содержит приватный ключ: сохранить его в секретах хостинга, не в репозитории и не в переписке.
3. Добавить переменные `VAPID_PRIVATE_KEY`, `VAPID_PUBLIC_KEY`, `VAPID_SUBJECT` (например, `mailto:owner@example.com`). Использовать постоянные ключи; замена требует переподписки устройств.
4. Перезапустить FastAPI с одним worker. Веб-процесс должен работать постоянно: при остановленном процессе напоминания не отправляются. Несколько процессов планировщика пока не поддерживаются.
5. Открыть сайт по HTTPS → Настройки → Настроить уведомления. Подключить устройство и нажать «Проверить доставку».

На iPhone с iOS 16.4+ сначала добавить сайт на экран «Домой», затем открыть установленное приложение и разрешить уведомления нажатием кнопки. Установка не выполняется автоматически. Системный фокус, разрешения и сеть могут задержать доставку. Ключ Gemini не заменяет VAPID.

## Офлайн и обновления

Кэш приложения содержит публичные локальные JS/CSS и изображения интерфейса. Приватные API-ответы находятся отдельно в IndexedDB по идентификатору аккаунта. При успешном выходе локальные данные аккаунта очищаются. Ранее открытые задания, расписание и заметки доступны при пропаже сети; неизвестные разделы потребуют подключения. Новые входы и ИИ без сети не работают. Фотографии из защищённых API не кэшируются service worker.

Изменения доски и заметок при сетевой ошибке сохраняются как локальные черновики. Синхронизация сравнивает исходную серверную версию; конфликт не перезаписывает её. В настройках есть скачивание конфликтного черновика в JSON. Перед сменой аккаунта нужно синхронизировать или скачать нужные черновики.

Обновление service worker применяется по кнопке после сохранения доски. Нет автоматической перезагрузки страницы при публикации новой версии.

## Проверка

`node --test tests/*.test.cjs`

`python -m unittest discover -s tests -v`

В тестах проверяются изоляция аккаунтов, корзина с материалами задания, ревизии документов, подзадачи, паузы, повторения, тихие часы и недопустимые push endpoints. Физическая доставка на iPhone требует реального HTTPS-хостинга, VAPID и разрешения пользователя; локальная проверка её не заменяет.
