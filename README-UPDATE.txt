StudyFlow — напоминания и кнопочный Telegram-бот

Заменить на GitHub: app.py, bot.py, start.py, static/app.js, static/style.css, static/index.html.
Важно: загружайте app.py именно под именем app.py (не app (1).py).
Не удалять /app/data, базу данных, uploads и переменные окружения.
Новые напоминания сохраняются в новой таблице reminders; существующие таблицы не удаляются.
В Bothost выполнить «Обновить из Git», затем перезапустить сервис.
Бот работает через polling в start.py при наличии TELEGRAM_BOT_TOKEN.
В разделе Telegram: подключение, тихие часы, точное время, дни, типы, тестовое уведомление.
В каждом сообщении бота есть ссылка на сайт и кнопка перехода.
Ограничение: для надёжной доставки нужен постоянно работающий процесс Bothost; если он спит, уведомления не отправляются.
Не запускайте одновременно вторую копию бота с тем же токеном: Telegram getUpdates конфликтует.
Для существующих пользователей старые общие настройки сохраняются; новые индивидуальные напоминания добавляются вручную.
