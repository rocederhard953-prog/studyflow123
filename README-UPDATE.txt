MY-STUDY — исправление загрузки фотографий ДЗ (полный архив)

Что исправлено:
- При создании ДЗ на сайте теперь можно выбрать сразу несколько фотографий.
- До сохранения виден предпросмотр выбранных изображений.
- Сначала создаётся задание, затем к нему прикрепляются фотографии через существующий защищённый API.
- В уже созданное ДЗ можно добавлять сразу несколько фотографий через «＋ Фото».
- Поддерживаются JPG, PNG, WEBP, GIF; максимум 8 МБ на файл по умолчанию.
- Если одна из фотографий не загрузилась, само задание сохраняется; выводится ошибка с именем файла.
- Сохранены функции предыдущего полного архива My-Study, включая Telegram-бота.

Установка через GitHub и Bothost:
1. СДЕЛАЙТЕ РЕЗЕРВНУЮ КОПИЮ БАЗЫ ДАННЫХ И КАТАЛОГА uploads.
2. Распакуйте архив. Содержимое архива (app.py, bot.py, start.py, static/) положите В КОРЕНЬ репозитория StudyFlow.
3. Замените в GitHub app.py, bot.py, start.py и папку static ЦЕЛИКОМ, включая static/bot_images/*.jpg.
4. Не создавайте вложенную папку myfix: в корне репозитория должен быть app.py, а рядом start.py и bot.py.
5. Не удаляйте DATA_DIR, существующую базу и папку uploads. Не изменяйте DATABASE_URL без необходимости.
6. В Bothost обновите приложение из GitHub и перезапустите его. Убедитесь, что установлены TELEGRAM_BOT_TOKEN, ADMIN_TELEGRAM_ID, SITE_URL и правильный DATA_DIR.
7. Откройте сайт с обновлением кэша (Ctrl+Shift+R). Проверьте «Домашние задания» -> «Новое задание» -> выбрать фото -> сохранить.
8. Проверьте добавление фото к существующему ДЗ через «＋ Фото», а также создание ДЗ с фото в Telegram.

Проверено: синтаксис Python/JavaScript, тест регистрации, создания ДЗ и загрузки вложения через FastAPI TestClient с временной SQLite БД. Работа на вашем Bothost и отправка реальных фотографий через Telegram здесь не проверялись.

Примечание: файл requirements.txt отсутствовал в предыдущем полном архиве. Если он есть в вашем GitHub, оставьте его без изменений. Для загрузки файлов FastAPI необходим python-multipart.
