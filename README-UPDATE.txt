StudyFlow: напоминания относительно событий и занятий

Новые режимы напоминаний:
- В указанное время (старый режим)
- За день до события в заданное время (например 19:00)
- За N минут до начала события (например 60 минут до первого урока)

Источник: расписание (начало первого урока дня) либо календарь (каждое событие).
Для двух уведомлений создайте два напоминания. Дни недели относятся к дню отправки.
Относительные уведомления не блокируются общими тихими часами: пользователь явно задает время.
Для расписания у уроков должно быть заполнено время начала в формате ЧЧ:ММ.

Установка: заменить app.py, bot.py, static/app.js, остальные файлы по желанию.
Не удалять папку data и DATABASE_URL. Новая таблица reminder_timings создаётся автоматически,
существующие reminders и другие данные не удаляются.

Проверка: python -m py_compile app.py bot.py; node --check static/app.js.
Доставка Telegram требует запущенного бота и TELEGRAM_BOT_TOKEN.
