# Помощник My-Study

Добавлен отдельный раздел «Помощник», плавающая кнопка на страницах сайта и кнопки «Помочь с ДЗ» у заданий.

## Что доступно сразу

Навигационный справочник работает без внешнего сервиса и расходов API: «Где добавить ДЗ?», «Как привязать Telegram?», «Как изменить время сводки?». Он предлагает кнопки перехода в существующие разделы. Это локальные подсказки, а не ответы языковой модели.

## Как включить объяснение домашних заданий

Подготовлено подключение OpenAI Responses API. Оплата API зависит от используемого сервиса и его тарифов; в проекте нет бесплатного встроенного доступа к модели. Новых расходов не возникает, пока API-ключ не добавлен и пользователь не отправил вопрос в учебном режиме.

1. Проверь, доступен ли сервис в твоей стране: https://developers.openai.com/api/docs/supported-countries.
2. Создай аккаунт и API-ключ в своём проекте OpenAI. Начни с официального руководства: https://developers.openai.com/api/docs/quickstart. Настрой оплату/доступ к API и модель, а также ограничения расходов в аккаунте сервиса.
3. В **переменных окружения текущего хостинга** задай `OPENAI_API_KEY` со значением своего ключа. Не вставляй ключ в чат, GitHub, HTML или JavaScript. Переменные читаются сервером, файл `.env` сам по себе приложением не загружается.
4. По умолчанию используется `AI_MODEL=gpt-5.4-mini`. Модель должна быть доступна твоему проекту и поддерживать Responses, изображения и JSON Schema. При необходимости модель меняется переменной `AI_MODEL`.
5. Обнови код из `main` и перезапусти существующий сервис `python start.py` / Docker. Сохрани DATA_DIR, существующую базу, uploads и настройки Telegram.
6. После входа открой «Помощник». Он должен показать готовность учебного режима. Начни с короткого вопроса без фото, затем проверь выбранное ДЗ.

Если OpenAI недоступен, не используй способы обхода ограничений. Для другого провайдера нужно заменить серверный транспорт в `assistant_service.py`; его нельзя подключить только заменой ключа OpenAI. Никакие внешние сервисы и аккаунты автоматически не регистрируются.

## Ограничения и контроль расходов

| Переменная | По умолчанию | Назначение |
|---|---|---|
| AI_ENABLED | 1 | Значение 0 отключает внешние ответы, оставляя навигацию |
| AI_USER_DAILY_LIMIT | 20 | Запросы одного пользователя за сутки UTC |
| AI_SITE_DAILY_LIMIT | 200 | Общий лимит запросов всего сайта за сутки UTC |
| AI_MAX_OUTPUT_TOKENS | 1800 | Максимум выходных токенов одного ответа, не более 4000 |

Лимиты запросов сохраняются в БД и не сбрасываются при перезапуске. Попытка обращения к внешнему сервису учитывается даже при его ошибке. Навигационные подсказки не расходуют лимит. Одновременно выполняется не более одного запроса одного пользователя и четырёх запросов на процесс. Сервер запускается в существующей конфигурации с одним worker. Лимиты запросов не заменяют денежный бюджет в аккаунте провайдера; стоимость зависит также от входного текста и изображений.

## Какие данные используются

Внешнему сервису отправляются текущий вопрос, последние сообщения этого диалога (до 10, всего до 16 000 символов) и **только выбранное пользователем задание**. Фотографии передаются только при явном включении соответствующего флажка: до двух фото JPG/PNG/WEBP, каждое до 4 МБ. Пароли, почта, полная база, Telegram ID и API-ключ в текст запроса не добавляются. Ключ используется только в серверном заголовке авторизации.

Сервер проверяет авторизацию, CSRF и принадлежность задания/фотографий пользователю. ИИ не получает инструментов изменения данных. Кнопки перехода допускают только заранее известные страницы. Текст модели отображается как текст, а не HTML. Учебные материалы и история описаны в системной инструкции как данные, а не команды.

Диалог находится только в оперативной памяти вкладки. Выход из аккаунта, новый диалог или перезагрузка его очищают; на сервере история не записывается. У провайдера применяются его собственные правила обработки данных: `store=false` отключает сохранение Response-объекта, но не означает автоматически полного отсутствия журналов у провайдера. Документация: https://developers.openai.com/api/docs/guides/your-data.

Таблица `ai_usage` создаётся при обычном запуске; для установок с Alembic добавлена миграция `0003_ai_usage`. Старые данные и административная кнопка бота не изменяются.

## Проверка

`python -m unittest discover -s tests -v`

`node --check static/app.js`

`node --check static/assistant.js`

Тесты используют временную базу и заглушку провайдера. Реальная генерация ответа без API-ключа не проверяется и не имитируется в рабочем интерфейсе.
