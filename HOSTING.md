# Настройка переменных на хостинге

Скопируй эти значения в Environment Variables / Переменные окружения.

```env
DATA_DIR=/app/data
COOKIE_SECURE=1
MAX_UPLOAD_MB=8
TELEGRAM_BOT_TOKEN=ВСТАВЬ_ТОКЕН_ОТ_BOTFATHER
```

`TELEGRAM_BOT_TOKEN` можно оставить пустым, если Telegram пока не нужен.

**Не добавляй** `APP_PASSWORD` или `SESSION_SECRET` — этот проект их не использует.

`PORT` обычно автоматически передаётся хостингом. Если платформа требует указать внутренний порт вручную, используй `8000` либо значение, прямо указанное в её настройках. Не привязывай приложение к домену: оно принимает запросы на `0.0.0.0`.

Обязательно подключи постоянный диск и смонтируй его в `/app/data` (или измени `DATA_DIR` на фактический путь монтирования). Внутри этой папки приложение создаст `studyflow.db` и `uploads/`.

Команда запуска без Docker: `python start.py`.
Команда установки: `pip install -r requirements.txt`.
Проверка после запуска: `/api/health`.
