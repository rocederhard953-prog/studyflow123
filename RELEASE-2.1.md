# My-Study 2.1

Новый экран «Мой день»: домашние задания с предметом и сроком, фотографии, расписание, прогресс привычек, фокус и цели. Тёмно-синяя тема с фиолетовыми акцентами, компактная навигация и мобильная панель. Старые разделы и пользовательские темы сохранены.

Telegram: шесть новых обложек, синие кнопки primary, предмет и срок в уведомлениях, выполнение задания, повтор через час и просмотр фотографий. Отложенные уведомления сохраняются в новой таблице task_snoozes. Обычные напоминания остаются в чате при навигации.

«Домашка на завтра» выбирается по сроку сдачи, независимо от расписания; задания с более поздней датой не попадают в это напоминание. Нового разделения по срочности не добавлено.

Вечерняя сводка объединяет уроки и ДЗ на завтра с невыполненными привычками сегодня. Однократно добавляется напоминание на 20:00 в часовом поясе пользователя; время можно изменить, сводку можно отключить или удалить. Пользовательские напоминания не перезаписываются.

## Обновление на текущем хостинге

Обновить исходники из main и перезапустить существующий сервис командой python start.py (или пересобрать Docker). Сохранить текущий постоянный диск DATA_DIR, базу, uploads и переменные окружения, включая TELEGRAM_BOT_TOKEN и SITE_URL. Нового токена и повторной привязки Telegram не требуется. Новая таблица создаётся при обычном старте; для установок с Alembic добавлена миграция 0002_task_snoozes. Никакие существующие записи не удаляются.

Проверка версии: GET /api/health → version 2.1.0. Если хостинг не разворачивает main автоматически, нужен штатный redeploy. Обновление GitHub само по себе не подтверждает публикацию на хостинге.

## Проверка

pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
node --check static/app.js

Тесты используют отдельную временную SQLite-базу и заглушки Telegram. Отправка сообщений в работающий бот локально не выполняется.

Обложки созданы встроенным image_gen в стиле midnight navy, cobalt blue и violet, с объёмными учебными символами и названиями разделов My-Study 2.1.
