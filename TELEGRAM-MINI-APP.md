# My-Study в Telegram

После обновления кода и перезапуска `python start.py` бот автоматически настраивает кнопку меню My-Study через `setChatMenuButton`. В новых сообщениях бота кнопка «Открыть My-Study» запускает Mini App, а «Открыть в браузере» открывает обычный сайт. Для обновления старого сообщения отправь `/start`.

В окружении хостинга должны быть заданы существующий `TELEGRAM_BOT_TOKEN` и `SITE_URL=https://my-study.bothost.tech`. URL должен использовать HTTPS. Новый бот и отдельный домен не требуются.

Mini App использует тот же сайт и базу. На телефоне показывается мобильное меню, а широкое окно Telegram Desktop использует обычную компоновку. Поддержаны изменение высоты окна, безопасные отступы Telegram и цвета выбранной темы. Нужна актуальная версия Telegram с поддержкой Mini Apps.

Вход выполняется логином и паролем My-Study. Сессия Telegram WebView может отличаться от браузерной; при первом открытии может потребоваться вход. Автоматический вход через Telegram не включён. Переданные клиентом данные Telegram не используются для доступа к аккаунтам.

Необязательно: чтобы добавить большую кнопку запуска в профиль бота, в BotFather открой `/mybots` → свой бот → Bot Settings → Configure Mini App → Enable Mini App и укажи URL сайта. Кнопка меню, настроенная сервером, работает независимо от этой настройки.

Документация Telegram: https://core.telegram.org/bots/webapps
